# Индивидуальный вклад

Для каждого участника указаны конкретные T, SR и D закреплённой области работы, связанные цепочки и фактический вклад с проверяемыми следами. Общие D используются несколькими участниками. Применение ИИ и человеческая проверка описываются в [AI_USAGE.md](AI_USAGE.md); будущие проверки не считаются выполненными.

**Закреплённая область работы:**

- **Решения:** [D-02](SECURITY_DESIGN.md#d-02--полное-серверное-посредничество-объектная-авторизация-и-безопасный-вывод), [D-03](SECURITY_DESIGN.md#d-03--серверные-поля-инварианты-и-атомарные-переходы).
