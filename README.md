# Сервис клубного членства

Сервис объединяет несколько клубов. Пользователь создаёт клуб или подаёт заявку в существующий, видит свои клубы в профиле и читает их материалы.

Создатель клуба становится его администратором. Администратор рассматривает заявки, добавляет и удаляет участников, обновляет материалы своего клуба. Суперпользователь удаляет клубы и не получает прав администратора в них.

## Доступ к материалам

В сервисе есть один тег: club-member. Он привязан к конкретному пользователю и конкретному клубу.

Тег club-member для клуба «Кино» открывает все материалы клуба «Кино». Он не открывает материалы других клубов. Пользователь может иметь этот тег в нескольких клубах.

Удалённый клуб скрывается из списка, а доступ к его материалам прекращается. Его данные сохраняются в архиве.

## Роли

| Роль | Возможности |
| --- | --- |
| User | Создаёт клубы, подаёт заявки, видит профиль и свои заявки |
| Administrator | Управляет заявками, участниками и материалами своего клуба |
| SuperUser | Удаляет клубы |

## Стек

- Go для сервера;
- TypeScript для браузерного клиента;
- PostgreSQL для хранения данных;
- HTTP и JSON для обмена между клиентом и сервером.
